# About Feature

## Purpose
Explains UniCycle's mission as a student-centred circular marketplace for pre-owned household essentials, showcasing campus sustainability metrics, how hall-to-hall handovers work, and an interactive FAQ.

## Structure
- `api/` — Types, Zod schemas, query keys, and mission/FAQ data (`about.api.ts`, `about.keys.ts`, `about.schema.ts`, `about.types.ts`).
- `state/` — Hook for FAQ accordion interaction and metrics (`useAbout.ts`).
- `components/` — Editorial About & Sustainability story view (`AboutView.tsx`).
- `pages/` — Route composition page (`AboutPage.tsx`).
